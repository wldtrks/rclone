# Privacy Policy

**Effective date:** November 12, 2026

This personal project ("Rclone Vault for Paperless") is a self-hosted integration used exclusively for personal data management. 

- **Data Collection:** This application interacts solely with designated cloud storage via Rclone to store personal, encrypted backups. It does not collect, harvest, or store any third-party user data.
- **Data Sharing:** No personal data is shared, sold, or transferred to third parties.
- **Contact:** If you have questions regarding this project, reach out via GitHub.
